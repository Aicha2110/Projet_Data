# Analyse des ventes

J’ai réalisé ce tableau de bord pour suivre les ventes, les bénéfices et les quantités vendues dans quatre régions : Central, East, South et West. Je voulais pouvoir passer d’une vue d’ensemble à une comparaison plus précise par année, par mois et par État.

Dans le rapport, on peut choisir l’année et l’indicateur à examiner. Les tendances mensuelles et leur moyenne aident à situer les variations. La carte et le classement par État montrent où les ventes sont réalisées. Un tableau compare les résultats de l’année sélectionnée avec ceux de l’année précédente.

J’ai aimé travailler sur cette comparaison : elle donne du contexte aux chiffres et aide à repérer les évolutions qui méritent d’être examinées. Le rapport ne donne pas à lui seul la cause d’une hausse ou d’une baisse ; il aide à voir où poursuivre l’analyse.

**Outils :** Power BI, DAX. Les données de ventes sont fournies dans un fichier Excel.
